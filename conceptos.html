5 Conceptos Clave de HTML

1. Etiquetas de texto

Permiten estructurar títulos, párrafos y destacar palabras importantes dentro del contenido escrito de una página web.

<p>Este es un texto con <strong>negrita</strong> y <em>cursiva</em>.</p>

2. Listas

Sirven para agrupar elementos relacionados. Pueden ser desordenadas (con viñetas usando <ul>) u ordenadas (numeradas usando <ol>).

<ul>
    <li>Primer elemento</li>
    <li>Segundo elemento</li>
</ul>

3. Enlaces

La etiqueta <a> conecta documentos entre sí mediante el atributo href, permitiendo navegar entre páginas locales o externas.

<a href="index.html">Ir al inicio</a>

4. Imágenes

Se insertan mediante la etiqueta vacía <img>, indicando la ruta del archivo en src y una descripción accesible en alt.

<img src="img_optimizadas/foto.jpg" alt="Descripción de la imagen" title="Texto emergente">

5. Tablas

Permiten organizar datos en filas y columnas de forma estructurada utilizando <thead>, <tbody> y <tfoot>.

<table>
    <thead><tr><th>Columna 1</th></tr></thead>
    <tbody><tr><td>Dato 1</td></tr></tbody>
</table>
